# Ideas borrowed from *Colony* (2026), and what they became

The film is a source of metaphors, not evidence. Each row is a design idea we had to justify on its own.

| Film idea | Colony feature | Built? |
|---|---|---|
| What one infected learns, all know | `brief`: one shared picture for any agent | yes |
| One mind sees through every host's eyes | one timeline of who did what (`brief`, git trailers) | basic |
| The ant mill: followers chase each other's trail in a circle | `antmill`: detect files agents keep flipping | yes |
| Overload, then the colony resets to a primitive state | roll back to last verified baseline | no |
| Sealed building | quarantine for unverified claims | no |
| Host dies, every infected freezes | `freeze`: pause shared writes | no |
| Last shot: one frozen infected moves | quarantined is dormant, never deleted (append-only) | by design |

Plot details come from public reviews and summaries, not from the film itself. Check them against the film before quoting in a README.
